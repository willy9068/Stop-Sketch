## 데모 실행
- `3_데모빌드/stopsketch_swarm_demo.html` 을 브라우저(Chrome 권장)로 열기 → 클릭 또는 스페이스 바로 출발
- 조작: 왼쪽 드래그 = 그리기 · 스페이스 = 시간 정지/재생 · 우클릭 = 선 빨아들이기 · 1~5·병 클릭 = 색 · 휠 = 줌 · R = 처음부터 · Esc = 일시 정지
