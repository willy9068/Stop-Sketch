# 스톱 앤 스케치 (가제, 구 잉크 런) 데모

자동으로 달리는 물방울 낙서 생물을 위해, 시간을 멈추고 선을 그려 길을 만들어 주는 2D 물리 그리기 액션 데모입니다.

## 실행
- **제출본:** `dist/stopsketch_demo.html` 더블클릭 (파일 하나로 동작, 외부 요청 없음)
- **개발본:** `src/index.html` 더블클릭 (일반 `<script>` 순서 로딩이라 서버 없이 열림)
- **레벨 툴:** `tools/level_editor.html` 더블클릭

## 조작
| 키 | 동작 |
|---|---|
| 클릭 / Space | 출발 (시작 화면). 점프는 없음 — 그림으로만 조작 |
| 마우스 왼쪽 드래그 | 선 그리기 (잉크 소모). 달리는 중에도 가능, 손을 떼면 바로 발판이 되고 5초 뒤 흐려지며 사라짐 |
| (자동) | 벽에 막히면 뒤로 돎 (레밍즈식), 별에 닿으면 획득 |
| Shift 또는 마우스 우클릭 | 시간 정지 / 다시 누르면 재생 (구간마다 정한 횟수). 멈춘 채 여유 있게 그리기 |
| R | 구간 처음부터 |
| N | (도착 후) 다음 구간 |
| 1 / 2 / 3 | 시간 정지 방식 A 완전 정지 / B 슬로 모션 0.3 / C 정지 + 3초 제한 (바꾸면 구간 다시 시작) |
| D | 디버그 패널 (구간 선택, FPS, 모드 전환, 정지 횟수·잉크 충전, 충돌 박스, 모드별 기록) |

## 레벨 툴 (`tools/level_editor.html`)
구간(레벨)을 그림으로 보며 배치하고 `src/levels.js` 로 저장합니다. 게임과 같은 그리기 코드를 써서 보이는 모습이 같습니다.

| 할 수 있는 것 | 방법 |
|---|---|
| 배경 지정 | 오른쪽 "구간 설정 → 배경" (bg_a 종이+구름 / bg_b 줄 노트 / bg_plain 빈 종이 / 단색) |
| 땅 | 땅 도구(G)로 드래그. 선택 후 양 끝·윗면 손잡이로 길이·높이 |
| 벽·발판 | 벽(W)·발판(P) 도구로 클릭. 벽은 클릭한 곳 땅 위에 섬. 8개 손잡이로 크기 조절 |
| 별(수집품) | 별(S) 도구로 클릭. 모서리 손잡이로 크기. 권장 구간당 3개 |
| 잉크 병 (성장용) | 잉크 병(I) 도구로 클릭. 먹으면 잉크 최대량 +300이 **계정에 영구 저장**. 병마다 id(b1, b2…)가 자동으로 붙음 (계정에 "구간id:병id"로 기록) |
| 잉크 웅덩이 | 웅덩이(U) 도구로 클릭 → 그 자리 땅 위에 깔림. 닿아 있는 동안 잉크가 초당 400 줄어듦 (선을 띄워 지나가야 함) |
| 별 평가 조건 | 오른쪽 "구간 설정 → 별 평가 조건": 목표 시간(초), 수집 별 모두, 시도 횟수. 만족한 조건 수 = 별 0~3 |
| 장식 | 장식(C) 도구로 클릭 → 오른쪽에서 그림 선택 (구름 등, 충돌 없음) |
| 글자 | 글자(T) 도구로 클릭 → 오른쪽 "문구"에 입력 |
| 시작·도착 | "시작"·"도착" 표시를 끌어서 옮김 (높이는 그 자리 땅에 자동) |
| 구간별 설정 | 이름, 잉크 양, 정지 횟수 |
| 여러 구간 | 위쪽 "+ 새 구간 / 복제 / ◀▶ 순서 / 삭제". 게임은 순서대로 진행 (도착 후 N) |
| 검사 | 시작·도착 아래 땅 없음, 겹친 땅, 별 개수, 벽에 묻힌 별, **필요 잉크 대략치 vs 잉크 양** |
| 표시 | 빨간 띠 = 그림으로 건너야 하는 틈(폭·높이차), "막는 벽 높이", 게임 화면 위·아래 끝 점선, 아래 미니맵 |
| 테스트 플레이 | ▶ 버튼(F5): 저장하지 않아도 지금 편집 중인 구간을 게임으로 바로 열어 봄 |
| 저장 | "levels.js 저장"(Ctrl+S) → 처음 한 번 `src/levels.js` 를 골라 덮어쓰기. 그 뒤로는 레벨 툴을 다시 열어도 **같은 파일에 바로 저장**(브라우저가 권한을 물으면 허용). 위쪽에 **"최근 저장: 파일 이름 · 날짜 시각"** 표시. "다른 곳에 저장"은 저장 창을 다시 띄움(지난번 폴더에서 열림). 브라우저는 보안상 폴더 전체 경로를 알려주지 않아 파일 이름만 보임. 파일 저장 창이 안 되는 브라우저는 내려받기 → 직접 덮어쓰기 |
| 되돌리기 | Ctrl+Z / Ctrl+Y. 저장 안 한 편집은 브라우저에 임시 보관되어 다음에 열 때 복구를 물어봄 |

단축키: 도구 V·G·W·P·S·I·U·C·T, Delete 삭제, Ctrl+D 복제, 방향키 1px(Shift 10px), Alt 누른 채 끌면 격자 무시, 오른쪽 버튼 드래그·휠로 화면 이동, Ctrl+휠 확대, Home/End 시작·도착으로.

저장한 뒤 제출본에 반영하려면 `python tools/build_single.py` 를 다시 실행합니다.

## 잉크·평가·계정 (사용자 결정 2026-10-19)
- 잉크는 모든 색 공용. 발판 선이 사라지면 그 길이만큼 다시 참. 잉크 웅덩이에 닿아 있으면 줄어듦
- 잉크 병을 먹으면 최대량이 영구히 늘어남 → 이 브라우저의 계정 저장(localStorage `stopsketch.save.v1`)에 기록. 이름을 바꾸기 전 저장(`inkrun.save.v1`)이 있으면 처음 한 번 옮겨 옴
- 클리어하면 조건 3개(목표 시간 · 수집 별 모두 · 시도 횟수)를 만족한 수만큼 별 0~3. 구간별 최고 기록도 계정에 저장
- 레벨 툴 테스트 플레이는 계정을 건드리지 않음 (복사본으로 실행)
- 디버그 패널(D) → "계정 초기화"로 잉크 성장·기록을 지울 수 있음

## 개발
```
node tools/test.js            # 순수 계산 테스트 (선 길이, 잉크, 정지 횟수, 시간 배율, 구간 검사)
node tools/sim.js             # 브라우저 없이 물리 시뮬레이션 (수치 조정 참고용)
python tools/build_single.py  # 단일 HTML 빌드 → dist/stopsketch_demo.html
```
- 수치는 `src/data.js`, 구간 배치는 `src/levels.js` 에 있습니다.
- 개발본을 고친 뒤에는 빌드를 다시 해야 제출본에 반영됩니다.

## 이미지 넣기
1. 배경을 지운 PNG를 `assets/` 에 정해진 파일명으로 저장 (원본은 `assets/original/` 또는 `D:\stopsketch\stopsketch_Image` 에 보관)
2. 게임·레벨 툴을 새로고침 → 바로 반영. 없는 파일은 색 블록 그대로 (개발본 콘솔에 404로 남지만 영향 없음)
3. 제출본 반영: `python tools/build_single.py` → 출력에 "이미지 n장 내장"과 없는 파일 목록이 나옴
4. 크기·테두리 조정은 `src/data.js` 의 `art` (캐릭터 크기 `charSize`, 9분할 테두리 `slices`, 땅 띠 `groundTop`, 배경 속도 `bgParallax`)
5. 어떤 모델·프롬프트로 만들고 무엇을 고쳤는지 `스톱앤스케치_AI이미지_프롬프트_ComfyUI.md` 7장 기록표에 적기

파일명과 쓰이는 곳, 새로 필요한 이미지와 프롬프트는 `스톱앤스케치_AI이미지_프롬프트_ComfyUI.md` 3장·8장에 있습니다. 게임이 읽는 이름 목록은 `data.js` 의 `art.images`.

| 그리는 방식 | 이미지 | 설명 |
|---|---|---|
| 9분할(nine) | `prop_wall`, `prop_platform` | 테두리는 그대로, 가운데·변은 같은 배율로 반복 → 아무 크기로 배치해도 무늬가 찌그러지지 않음 |
| 세로 쌓기(stack) | `obs_wall` (prop_wall 없을 때) | 폭에 맞춰 위에서부터 쌓음 |
| 가로 반복 | `ground_top` (땅 윗면), 배경 | 이음매 없는 이미지 필요 |
| 무늬 채우기 | `ground_fill` (땅 속) | 사방 이음매 없는 이미지 필요 |
| 상태별 캐릭터 | `char_idle` / `char_run` / `char_jump`(튀어 오름) / `char_fall`(떨어짐) / `char_erased`(실패) | 없는 것은 char_idle |

## 구조
| 파일 | 하는 일 |
|---|---|
| `src/data.js` | 모든 수치·색·프랍 종류·이미지 목록 |
| `src/levels.js` | 구간 배치 (레벨 툴이 저장) |

| `src/physics.js` | Matter.js 감싸기 |
| `src/props.js` | 땅·프랍 그리기(9분할 등)와 물리 바디 — 게임·레벨 툴 공용 |
| `src/level.js` | 구간 데이터 → 물리 바디, 별 목록 |
| `src/player.js` | 자동 달리기, 바닥·벽 판정, 뒤로 돌기 |
| `src/draw.js` | 선 그리기 → 선분 체인 물리 바디, 선 수명 |
| `src/game.js` | 게임 상태, 정지/재생, 별 획득, 한 스텝 진행 (화면과 무관) |
| `src/assets.js` | 이미지 불러오기 (`assets/` 또는 제출본 내장, 없으면 색 블록) |

| `src/debug.js` | 디버그 패널 |
| `src/main.js` | 입력, 구간 선택, 레벨 툴 테스트 모드(`#test=`), 고정 타임스텝 루프 |

| `tools/level_editor.html`, `tools/editor.js` | 레벨 툴 (제출본에는 포함 안 됨) |
| `docs/screenshots/` | 확인용 화면 |
