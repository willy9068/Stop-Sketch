# 스톱 앤 스케치 — 물방울 무리 시험판 (2026-10-20)

기존 데모(`../stopsketch/`)는 그대로 두고, 2026-10-20 논의한 **물방울 무리 방식**을 따로 시험하는 폴더입니다.
결정 내용 전체는 `../stopsketch/DEVLOG.md` 의 "검토 중인 아이디어: 물방울 무리 + 검은 잉크병 정화"와 "3일차" 섹션에 있습니다.

## 실행
- **개발본:** `src/index.html` (더블클릭으로도 열림. 이미지는 `../stopsketch/assets/` 를 같이 씀)
- **제출본:** `dist/stopsketch_swarm_demo.html` (파일 하나, 외부 요청 없음)
- **레벨 툴:** `tools/level_editor.html` — 저장은 `stopsketch_swarm/src/levels.js` 에 (기존 데모 레벨 툴과 저장 기억이 따로)

## 규칙 (사용자 결정 2026-10-20)
- 주인공 물방울 1 + 길 위·우리 안에 **잠든 작은 물방울**. 걷는 물방울이 닿으면 깨어나 그 물방울이 가던 방향으로 함께 걸음. 물방울끼리 서로 통과
- **검은 잉크병**(도착)에 닿은 물방울은 흡수되고 병이 검정 → 하늘색으로 정화됨
- 주인공이 죽으면 실패. 주인공만 도착해도 성공. 주인공이 도착하면 **Enter / 위 가운데 버튼으로 스킵**(남은 물방울은 죽은 것). 걷는 물방울이 없으면 바로 클리어
- 평가 별 = 목표 시간 안 · **물방울 n% 이상 도착**(배치된 작은 물방울 기준, 기본 100%) · 시도 횟수 안
- **선은 사라지지 않고 중력으로 떨어짐** (한 덩어리, 회전). 다리는 양쪽 땅에 걸쳐야 버팀. 정지 중에 그린 선은 재생할 때 떨어짐
- **우클릭: 선 빨아들이기** — 잉크 전부 돌려받음, 달리는 중에도 가능, 위에 물방울이 있어도 가능
- 물감 5색: **1 검정**(기본) · **2 빨강**(밟으면 선과 수직으로 튕김) · **3 파랑**(밟는 동안·내린 뒤 잠깐 빠름) · **4 노랑**(그은 자리의 배치된 선을 끊음, 노랑 선은 바로 사라짐) · **5 초록**(떨어지지 않고 천천히 떠올라 닿으면 고정)
- **배치된 선**(검은 다이아몬드 막대): 고정. 노랑으로 자르면 "붙은 끝"이 있는 조각만 남고 나머지는 떨어짐 (레벨 툴에서 붙은 끝 지정)
- **가시**: 닿으면 죽음. 선을 떨어뜨려 덮으면 지나갈 수 있음
- 끼이면 죽지 않고 가까운 옆으로 밀려남. 죽는 경우 = 떨어짐 · 지우개 · 가시
- **지우개**: 출발 3초 뒤 왼쪽 화면 밖에서 주인공 속도의 20%로 따라옴, 정지 중엔 멈춤
- **정지 +1 아이템**(그 스테이지에서만), 아이템은 아무 물방울이나 먹을 수 있음. 잉크 웅덩이 없음
- **물방울 속도·서로 충돌** (사용자 요청 2026-10-20): 레벨 툴 "스테이지 설정 → 물방울"에서 스테이지마다 주인공 속도·작은 물방울 속도(기본 5.2 = 초당 약 312px)와 서로 충돌 켬/끔(기본 끔 = 통과). 지우개 속도는 주인공 속도 기준
- 카메라: 걷는 물방울이 다 보이게 자동 줌(최소 0.5배), **마우스 휠이 우선**이고 3초 뒤 자동으로. 화면 밖 물방울은 가장자리 화살표

## 조작
| 키 | 동작 |
|---|---|
| 클릭 / 스페이스 | 출발 |
| 마우스 왼쪽 드래그 | 선 그리기 |
| 스페이스 | 시간 정지 / 재생 (스테이지마다 정한 횟수) |
| 마우스 우클릭 | 선 빨아들이기 |
| 1~5 · 아래 병 클릭 | 물감 색 |
| 마우스 휠 | 카메라 줌 |
| Enter | 주인공 도착 후 스킵 |
| R / N / D | 처음부터 / 다음 스테이지 / 디버그 |

## 레벨 툴: 구간 경계 (사용자 요청 2026-10-20)
- 화면 위쪽 보라색 "▶ 이름" 표시 = 구간 경계. **이름표나 보라 점선을 클릭해 선택 → 끌어서 옮기기**, 오른쪽 "선택한 것"에서 x·이름 바꾸기, 복제(Ctrl+D)·삭제(Delete), 방향키 1px(Shift 10px)
- **구간 경계 도구(J)**: 클릭한 x에 새 경계 → 이름 칸에 바로 입력. "스테이지 설정 → 구간 경계" 글 상자로도 고칠 수 있음
- 저장할 때 x 순서로 정렬해 levels.js 에 들어감. 설계 표시만이고 게임 규칙에는 영향 없음

## 스테이지 = 구간들 (사용자 결정: 스테이지는 구간으로 이루어짐, 구간은 설계 용어)
| 스테이지 | 색 | 구간 |
|---|---|---|
| 1 · 물방울 모으기 | 검정·빨강 | 이동 → 퍼즐 1 틈(검정 다리) → 퍼즐 2 가시 구덩이(선으로 덮기) → 퍼즐 3 절벽(빨강) → 도착. 물방울 5 |
| 2 · 다섯 색 | 5색 | 이동 → 퍼즐 1 다이아몬드 우리(노랑으로 벽 아래 끊기) → 퍼즐 2 우물(초록 엘리베이터, 그 뒤 검정 다리) → 아이템(정지 +1) → 퍼즐 3 넓은 틈(파랑+빨강) → 도착. 물방울 10 |
