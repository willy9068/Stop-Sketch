## 규칙 (사용자 결정 2026-10-20)
- 주인공 물방울 1 + 길 위·우리 안에 **잠든 작은 물방울**. 걷는 물방울이 닿으면 깨어나 그 물방울이 가던 방향으로 함께 걸음. 물방울끼리 서로 통과
- **검은 잉크병**(도착)에 닿은 물방울은 흡수되고 병이 검정 → 하늘색으로 정화됨 (2026-10-21: 정화 ^ 0.5 로 빨리 밝아지고 100% 면 물방울 기본색, 물방울 색은 섞이지 않음)
- 대열 물방울 발밑의 바닥이 사라지면(회수·노랑·떨어지는 다리 등) **대열에 남은 채 떨어지고**, 착지하면 기다렸다가 자기 자리로 통 튀어 복귀. 떨어지는 도중 선·벽 옆면에 부딪히거나 빨강에 튕기면 이탈 (사용자 결정 2026-10-21)
- 주인공이 죽으면 실패. 주인공만 도착해도 성공. **주인공이 도착하면 이탈한 물방울은 죽은 것**으로, 대열이 다 들어가면 결과 창 (2026-10-21: 스킵 끔, `goalEnter.skip`)
- 평가 = **수집 별 n/3**(주인공이 닿아야 획득) + **정화 %**(도착한 물방울 / 전체) (사용자 결정 2026-10-20, 시간·시도 조건은 없앰)
- **선은 사라지지 않고 중력으로 떨어짐** (한 덩어리, 회전). 다리는 양쪽 땅에 걸쳐야 버팀. 정지 중에 그린 선은 재생할 때 떨어짐
- **우클릭: 선 빨아들이기** — 잉크 전부 돌려받음, 달리는 중에도 가능, 위에 물방울이 있어도 가능
- 물감 5색: **1 검정**(기본) · **2 빨강**(밟으면 선과 수직으로 튕김. 60° 넘게 세운 빨강은 부딪힌 쪽으로 튕기고 걷는 방향도 바뀜 — 2026-10-22) · **3 파랑**(밟는 동안·내린 뒤 잠깐 빠름) · **4 노랑**(그은 자리의 배치된 선을 끊음, 노랑 선은 바로 사라짐) · **5 초록**(떨어지지 않고 천천히 떠올라 닿으면 고정)
- **배치된 선**(검은 다이아몬드 막대): 고정. 노랑으로 자르면 "붙은 끝"이 있는 조각만 남고 나머지는 떨어짐 (레벨 툴에서 붙은 끝 지정)
- **가시**: 닿으면 죽음. 선을 떨어뜨려 덮으면 지나갈 수 있음
- 끼이면 죽지 않고 가까운 옆으로 밀려남. 죽는 경우 = 떨어짐 · 지우개 · 가시 · 투사체
- **지우개**: 출발 3초 뒤 왼쪽 화면 밖에서 주인공 속도의 20%로 따라옴, 정지 중엔 멈춤
- **정지 +1 아이템**·**잉크 병**(+300, 병마다 양 지정) 모두 그 스테이지에서만 (잉크 병: 사용자 결정 2026-10-22, 계정 영구 성장 안 씀). 아이템은 아무 물방울이나 먹을 수 있음. 잉크 웅덩이 없음
- **발사기** (사용자 결정 2026-10-22): 정한 방향·간격으로 **색 투사체**(검정·빨강·파랑·초록)를 쏨. **같은 색으로 그린 선에만 막히고** 다른 색은 통과, 땅·벽·발판·가시·배치된 선에도 막힘. 주인공이 맞으면 실패, 작은 물방울은 잃음. 선은 그대로. 정지 중엔 안 쏘고 투사체도 멈춤
- **물방울 속도·서로 충돌** (사용자 요청 2026-10-20): 레벨 툴 "스테이지 설정 → 물방울"에서 스테이지마다 주인공 속도·작은 물방울 속도(기본 5.2 = 초당 약 312px)와 서로 충돌 켬/끔(기본 끔 = 통과). 지우개 속도는 주인공 속도 기준
- 카메라 (사용자 결정 2026-10-21): **주인공과 대열만 따라감**, 이탈한 물방울 때문에 줌 아웃하지 않음 → 화면 밖 물방울은 가장자리 화살표, 보고 싶으면 휠로 직접 줌 아웃. **마우스 휠이 우선**이고 3초 뒤 기본 줌으로. 기본 줌·화면 위 끝·아래 끝은 스테이지마다 (레벨 툴 "스테이지 설정 → 카메라")
- 정지 횟수·잉크 **무제한** 켬/끔 (레벨 툴 "스테이지 설정", 2026-10-21)
- **사운드** (사용자 결정 2026-10-22, `src/sound.js`): 개발본을 파일로 직접 열면(file://) 배경 음악은 `<audio>` 로 재생 (정지 중엔 음량만 줄어듦, 2026-10-23). 배경 음악 1곡 반복 + 효과음 22개. **2026-10-23 효과음은 뺌 — 지금은 배경 음악만** (`data.js sound.useSfx: false`). 파일은 `../stopsketch/assets/sound/<이름>.(mp3|ogg|wav|flac)` (없으면 안 남, 목록·프롬프트는 `스톱앤스케치_사운드_프롬프트_ComfyUI.md`). 정지 중 음악이 먹먹해짐, 무리 소리는 간격을 두고 음을 올림, 지우개 소리는 가까울수록 큼, Esc 일시 정지 중엔 모든 소리 멈춤. 음량 기본값은 UI 툴 `musicVolume`·`sfxVolume`
- **지우개 끄기** (테스트용, 레벨 툴 "스테이지 설정 → 지우개", 2026-10-22). 제출 전에 다시 켤 것

## 레벨 툴: 발사기·잉크 병 (사용자 결정 2026-10-22)
- **발사기 도구(O)**: 선택 칸에서 쏘는 방향(0 오른쪽 · 90 아래 · 180 왼쪽 · −90 위)·간격(ms)·속도·첫 발(ms, 출발 뒤 게임 시간)·투사체 색. 포구 쪽 손잡이를 끌거나 Q/E 로 방향, 점선 = 날아가는 길. 상자는 돌리지 않음
- **잉크 병 도구(I)**: 선택 칸 "잉크 양" (기본 300)
- 검사: 발사기 색을 그 스테이지에서 못 쓰면 주의, 잉크 병 개수·합계 정보

## 레벨 툴: 구간 경계 (사용자 요청 2026-10-20)
- 화면 위쪽 보라색 "▶ 이름" 표시 = 구간 경계. **이름표나 보라 점선을 클릭해 선택 → 끌어서 옮기기**, 오른쪽 "선택한 것"에서 x·이름 바꾸기, 복제(Ctrl+D)·삭제(Delete), 방향키 1px(Shift 10px)
- **구간 경계 도구(J)**: 클릭한 x에 새 경계 → 이름 칸에 바로 입력. "스테이지 설정 → 구간 경계" 글 상자로도 고칠 수 있음
- 저장할 때 x 순서로 정렬해 levels.js 에 들어감. 설계 표시만이고 게임 규칙에는 영향 없음

## 레벨 툴: 여러 개 선택·화면 끝 (사용자 요청 2026-10-21)
- **Ctrl+클릭**으로 선택에 더하기/빼기 → 그중 하나를 끌면 모두 함께 옮겨짐. **Ctrl+빈 곳 드래그** = 상자로 선택. 방향키·Delete 도 모두에. Esc 해제
- 파란 점선 = **게임 화면 위 끝·아래 끝** (카메라가 그 밖은 안 보여 줌). 왼쪽 파란 이름표나 빈 곳의 점선을 끌어 옮기거나 "스테이지 설정 → 카메라"에서 숫자로. 초록 점선 = 시작할 때 게임 화면(기본 줌)

## 레벨 툴: 회전·비탈길 (사용자 요청 2026-10-21)
- 선택한 것의 **동그란 위 손잡이**를 끌거나 **Q/E**(땅 5도·물건 15도, Shift 1도), 오른쪽 "각도"·"경사" 칸
- 땅은 윗면만 기울어짐(아랫면 평평, ±60도): + 내리막 / − 오르막. 벽·발판·가시는 물리도 돌아감, 별·물방울·장식·글자는 그림만
- **오르막 속도** (사용자 결정 2026-10-21): 10도 이하 그대로 · 20도 이하 75% · 30도 이하 50%. 31도부터는 스스로 못 오르고 미끄러지면 반대 방향으로 감 → 파랑 가속(비탈 25도 완만) 등 도움이 필요. 그린 선도 같음
