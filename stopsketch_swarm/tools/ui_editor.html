UI·글자 툴 — 물방울 무리판
왼쪽 칸을 고치면 오른쪽 미리보기에 바로 보입니다. 칸을 누르면 그 글자가 나오는 장면으로 바뀝니다.
글자 칸에서 Enter = 줄바꿈 (게임에서도 여러 줄로 나옴). 결과 창 버튼은 미리보기(클리어·실패 결과)에서 끌어서 옮길 수 있습니다.
{이름} 자리에는 게임이 숫자·이름을 넣습니다 (지우면 그 값이 안 나옴). 노란 칸 = 처음과 달라진 칸, ↺ = 그 칸만 처음대로.
저장한 uitext.js 는 stopsketch_swarm/src/uitext.js 를 덮어쓰고, 제출본은 python tools/build_single.py 로 다시 만듭니다.
물감 이름은 레벨 툴에도 같이 쓰입니다. 위치·크기는 게임 화면 1280×720 기준 px.
