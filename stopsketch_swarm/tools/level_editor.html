사용법

왼쪽 도구를 고르고 화면을 클릭하면 놓입니다 (Shift를 누른 채면 계속 놓기).
땅은 드래그해서 길이를 정합니다.
선택한 것은 끌어서 옮기고, 네모 손잡이로 크기를 바꿉니다.
Delete 삭제 · Ctrl+D 복제 · 방향키 1px (Shift 10px)
Ctrl+클릭: 여러 개 선택(더하기·빼기) → 하나를 끌면 모두 함께 옮겨짐 · Ctrl+빈 곳 드래그: 상자로 선택 · Esc 해제
Ctrl+Z 되돌리기 · Ctrl+S 저장 · F5 테스트 플레이
휠: 마우스 위치 기준 확대·축소 · 화면 이동: 오른쪽·가운데 버튼 드래그, Space+드래그, Shift+휠(가로)
땅: 위 손잡이 = 윗면(아랫면 그대로), 아래 손잡이 = 높이, 양옆 = 폭, 동그란 위 손잡이 = 경사(비탈길)
회전: 모든 물건은 동그란 위 손잡이를 끌거나 Q/E (땅 5도·물건 15도, Shift 1도), 오른쪽 "각도" 칸
Home 시작으로 · End 도착으로 · 아래 미니맵 클릭으로 이동
빨간 띠 = 그림으로 건너야 하는 틈 · 파란 점선 = 게임 화면 위·아래 끝 (카메라가 그 밖은 안 보여 줌, 이름표나 선을 끌어 옮김) · 초록 점선 = 시작할 때 화면 (기본 줌)
